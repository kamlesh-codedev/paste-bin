# PasteVault

A full-stack Pastebin-style platform for creating, storing, retrieving, managing, and sharing text and code snippets.

## Tech Stack

- Frontend: React + Vite
- Backend: Flask
- Database: PostgreSQL
- ORM: SQLAlchemy
- Authentication: JWT
- API Documentation: OpenAPI / Swagger
- Testing: Pytest
- Containerization: Docker
- Orchestration: Docker Compose
- CI/CD: GitHub Actions
